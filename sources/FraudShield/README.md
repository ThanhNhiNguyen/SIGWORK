# FraudShield source candidates

Paper supplied for SIGWORK:
"Fraud Shield: Credit Card Fraud Detection with Ensemble and Deep Learning"

The paper's methodology describes PCA, SMOTE, normalization, feature selection with Extra Trees + Information Gain + LASSO, Voting (Random Forest + Gradient Boost + Logistic Regression), Stacking with Decision Tree, and CNN/LSTM/hybrid models.

The following public repositories were found by name search, but neither was verified as the authors' official implementation of the supplied paper:
- https://github.com/rohith-chitturi/FraudShield_AI
- https://github.com/Omensah-15/FraudShield
