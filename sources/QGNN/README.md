# Source: estasz/GNN-QGNN-FraudDetection

Repository: https://github.com/estasz/GNN-QGNN-FraudDetection

This repository contains GNN-QGNN.ipynb and describes a classical GNN and a Quantum Graph Neural Network for credit-card fraud detection. Its README specifies a GraphSAGE/GCN baseline and an SGConv-based QGNN with a simulated quantum circuit using NVIDIA CUDA-Q.
