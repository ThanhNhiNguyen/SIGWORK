# SIGWORK Algorithm Sources

This directory contains source repositories/code identified during the SIGWORK literature-review workflow.

IMPORTANT:
- A source is copied only when it is public and accessible through GitHub.
- "Candidate" does not mean "official author implementation".
- Verify each source against the corresponding paper before reporting reproduction results.
